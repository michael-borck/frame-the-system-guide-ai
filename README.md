# Frame the System, Guide the AI

*Systems Analysis and Design in the AI Era* by Michael Borck.

A short book for analysts, product owners and developers who have to frame a problem, make requirements checkable, model decisions and hand over a system that may contain AI.

## Structure

- `index.qmd`: preface and reading guide
- `chapters/`: ten chapters in four parts
- `appendices/`: artefact templates and an AI system checklist
- `book-design.css` / `book-design-epub.css`: house design assets
- `_quarto.yml`: HTML, PDF and EPUB configuration

## Build

```bash
quarto render
```

For the Lorekeeper pack, the engine reads the four parts and appends interactive lessons from `lorekeeper/books/systems-analysis-and-design/`.
